### Comandos base

```bash
SER=adb-RQCX209WR1Z-E8tEKj._adb-tls-connect._tcp

adb -s "$SER" logcat -c
adb -s "$SER" logcat -v time -s ChatRouter SourceGate CopilotLLM CopilotM1

# captura de tela
adb -s "$SER" exec-out screencap -p > /tmp/opencode/casoN.png

# dump da UI
adb -s "$SER" shell uiautomator dump /sdcard/window.xml
adb -s "$SER" shell cat /sdcard/window.xml | sed 's/></>\n</g' \
  | grep -E 'text=|content-desc='

# digitar (ajuste as coordenadas ao layout da A34)
adb -s "$SER" shell input tap 300 1930
adb -s "$SER" shell am broadcast -a ADB_CLEAR_TEXT
B64=$(printf '%s' 'TEXTO AQUI' | base64 -w0)
adb -s "$SER" shell am broadcast -a ADB_INPUT_B64 --es msg "$B64"
adb -s "$SER" shell input tap 980 2080
```

> O broadcast `ADB_INPUT_B64` exige o receptor de input ADB instalado no
> aparelho. Se não estiver disponível, use `adb shell input text` (espaços
> como `%s`) e confira o campo antes de enviar.

## 3. Critérios de PASS/FAIL

**Críticos (100%):**

- alvo/card correto (2–5);
- status e ações corretos (10, 12, 13);
- nenhuma ref/número/citação inventada;
- nenhuma recusa falsa com fonte disponível;
- cobertura real no caso 14.

**Não críticos (meta ≥ 80%):**

- forma/tamanho (2, 15);
- ausência de meta/preâmbulo;
- latência.

**Evidência por caso:** print + trecho do logcat + card/reader + status do
chip.
