## 2. Stop

Pergunta em Profundo; stop durante o streaming:

```text
CopilotM1: turn=turn-5eea8b23-... phase=STREAMING partial=1 reasoning=4657
CopilotM1: turn=turn-5eea8b23-... cancelled partial=971 reasoning=4657
CopilotM1: turn=turn-5eea8b23-... phase=CANCELLED partial=971 reasoning=4657
CopilotM1: turn=turn-5eea8b23-... cancelled persisted message=msg-53af1808-...
CopilotM1: turn=turn-5eea8b23-... end phase=CANCELLED final=msg-53af1808-...
```

Payload gravado:

```json
{
  "text": "Boa — mas primeiro um ajuste de rota...",
  "origin": "COPILOT",
  "turnId": "turn-5eea8b23-2e68-4cfa-a8b9-650f2b10d6ec",
  "cancelled": "1",
  "partial": "1",
  "reasoningSeconds": "8"
}
```

## 3. Reabrir o app

Depois de `force-stop` + abrir a nota/seção, o item continuou:

- “Pensou por 8s”;
- parcial de 971 chars;
- “Geração parada.”;
- “Tentar novamente” / “Fechar”.

O banco manteve a mensagem `msg-53af1808-...`; ela não é mais um estado
transitório.

## 4. Retry

“Tentar novamente” no CANCELLED persistido:

```text
CopilotM1: turn=turn-ac74f737-... phase=WAITING
CopilotM1: turn=turn-ac74f737-... phase=STREAMING
CopilotM1: turn=turn-ac74f737-... done message=msg-def1a7a3-...
```

Banco, em ordem:

```text
msg-53af1808-...  cancelled=1  turn-5eea8b23-...
msg-def1a7a3-...  DONE         turn-ac74f737-...
```

O CANCELLED anterior permaneceu; a resposta nova entrou **abaixo**, sem
duplicar. O retry não reativa o turno antigo.

## 5. Checks rápidos

- **“Pensou por 9s” × “7s”:** são turnos diferentes. O 9s foi
  `turn-8d9926a2-...` (16:50) e o 7s foi `turn-4ed75cbe-...` (16:56, após
  restart). Não é regressão do mesmo turno.
- **Skeleton de escopo:** implementado (`scopeLoading` até a primeira
  emissão real do Room + `ScopeSkeleton`). Não foi possível isolar
  visualmente no A34 porque a troca testada caiu em uma seção com
  mensagens; fica como validação de UI pendente, sem impacto no M1.1.

## 6. Limites

- O texto do raciocínio continua transitório; o CANCELLED persistido guarda
  os segundos para “Pensou por Xs”.
- “Fechar” faz soft delete da mensagem CANCELLED.
- O partial persistido é o último snapshot do streaming no momento do stop;
  não continua sendo atualizado.
- Tablet segue como gate da v2.9.0; keystore em outra máquina é gate de
  distribuição.
