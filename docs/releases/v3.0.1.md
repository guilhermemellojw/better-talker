# Better Talker v3.0.1

**versionCode:** 32 · **ABI:** arm64-v8a · **Distribuição:** APK sideload (GitHub Releases)

## O que mudou

### Referências de revista: página/§ que antes se perdiam

- `Despertai! 08/13 pág. 6` → `g|2013|8`, **page=6**.
- `Despertai! 08/13 pág. 8 parág. 1-2` → page=8, **§1-2**.
- `Sentinela número 3 de 2019 pág. 6-7` → `wp|2019|3`, **pág. 6-7**.
- `Sentinela de julho de 2025 pág. 22 § 8-9` → page=22, §8-9.

O resolvedor agora devolve:

- página + § indexados → **RESOLVED**;
- página sem § → **PARTIAL** com o texto real da página;
- § sem página → **PARTIAL** via `byParagraphRange`;
- página + § em índice antigo sem numeração → **PARTIAL** pela página;
- PDF/EPUB sem página/§ → **PARTIAL por contexto** (frase do esboço acima
  do threshold);
- contexto fraco → **UNRESOLVED** com motivo e ação, nunca “não existe”.

### JWPUB confiável

- Corrigido o schema do `lmd_T.jwpub` (`ContentLength` não existe no schema 9;
  usa `length(Content)`).
- `ParagraphNumberLabel` ausente em JWPUB antigo (`g_T_201308`) tem fallback
  para `ParagraphIndex`.
- Páginas impressas do HTML (`pageNum/data-no`) são preservadas.
- Cache de extração usa UUID; `reindexAll` em paralelo não colide mais
  (`invalid entry CRC`/`ENOENT`).
- Mensagens específicas para JWPUB inválido/corrompido, com **Reindexar** e
  **Baixar EPUB**; removida a frase falsa “JWPUB ainda não suportado”.
- Download direto continua preferindo **JWPUB > EPUB > PDF** e mostra o
  formato escolhido.

### “Fontes e apoio” unificado

- Removido o card “Fontes deste ponto” acima do composer.
- O conteúdo do ponto entrou no disclosure “Fontes e apoio”, colapsado por
  padrão, com um único controle e reduced motion.
- Mostra texto encontrado + “Verificar”, contagens, “Ver todas”, “Texto usado”
  e “Reanalisar”. “Do turno” continua no mesmo lugar.
- “Fontes necessárias” segue separado e acionável.

## Instalação

1. Baixe o `app-release.apk` e o `app-release.apk.sha256`.
2. Confira o SHA-256:

   ```bash
   sha256sum app-release.apk
   ```

3. **Se você tem build de debug instalada, desinstale antes.** A assinatura
   é diferente; a desinstalação apaga os dados locais.

## Privacidade

As notas ficam no aparelho. A chave da API do DeepSeek é guardada cifrada no
Android Keystore. Quando o Copilot é usado, o texto do chat e o contexto
selecionado são enviados por HTTPS à API do DeepSeek; sem chave, o app usa
apenas o motor determinístico local. O backup do Android está desligado. O
reconhecimento de voz não grava áudio; quando o modo no aparelho está
disponível, o áudio não sai do dispositivo.
