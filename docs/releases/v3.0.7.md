# Better Talker v3.0.7

**versionCode:** 38 · **ABI:** arm64-v8a · **Distribuição:** APK sideload (GitHub Releases)

## O que mudou

### Export/import local (ZIP + JSON)

- **Configurações → Dados → Exportar backup:** gera um ZIP com
  `manifest.json` (formato, schema, versão, contagens e SHA-256) e
  `data.json`.
- **Importar backup:** valida formato, schema, checksum, contagens e
  referências antes de tocar no banco. Depois cria um **backup automático
  do estado atual** e importa em **transação Room**.
- Inclui: pastas, notas, esboços, seções/subpontos, S-34, metadados de
  anexos e tombstones.
- **Não inclui:** arquivos das publicações, passagens indexadas, histórico
  do Copilot e chave da API. Anexos voltam como metadados; baixe o arquivo
  de novo na Biblioteca.
- Import é **merge/upsert**: notas com o mesmo ID são substituídas pela
  versão do backup; dados locais que não estão no backup permanecem. O
  backup automático cobre o caso de importar um arquivo antigo.

### Segurança do build debug

- O build **debug** agora usa `applicationIdSuffix ".debug"`. Ele não
  instala mais por cima do release `com.bettertalker.app` nem toca nos
  dados do usuário.

## Limites

- Arquivos das publicações **não** vão no ZIP; os metadados são
  preservados e o arquivo pode ser baixado de novo.
- Histórico do Copilot **não** é exportado nesta versão.
- O ZIP não tem senha/criptografia; é um arquivo local escolhido por você.
  Não há sync/nuvem.
- O import não substitui o banco inteiro: ele faz merge por ID. Para uma
  migração limpa, importe em um aparelho novo (ou depois de limpar os
  dados do app).
- O S-34 é exportado para os anexos que ainda existem no acervo; outlines
  S-34 órfãos (sem anexo) não entram.

## Instalação

1. Baixe o `app-release.apk` e o `app-release.apk.sha256`.
2. Confira o SHA-256:

   ```bash
   sha256sum app-release.apk
   ```

3. Builds **debug** usam `com.bettertalker.app.debug` e **coexistem** com o
   release. Só desinstale um build antigo que ainda use o mesmo
   `applicationId` do release (`com.bettertalker.app`) e assinatura
   diferente; nesse caso, a desinstalação apaga os dados locais.
4. Antes de instalar, rode `./scripts/preflight-install.sh <apk>`
   (checklist em `docs/operations/preflight-install.md`).

## Privacidade

As notas ficam no aparelho. A chave da API do DeepSeek é guardada cifrada no
Android Keystore. Quando o Copilot é usado, o texto do chat e o contexto
selecionado são enviados por HTTPS à API do DeepSeek; sem chave, o app usa
apenas o motor determinístico local. O backup do Android está desligado. O
reconhecimento de voz não grava áudio; quando o modo no aparelho está
disponível, o áudio não sai do dispositivo.
