# Better Talker v3.0.4

**versionCode:** 35 · **ABI:** arm64-v8a · **Distribuição:** APK sideload (GitHub Releases)

## O que mudou

### Matcher de edição (C2.6)

- Ano de 4 dígitos no nome do arquivo precisa ser o ano da edição.
- Nomes oficiais da API (`*_T_YYYYMMDD`/`*_T_YYYYMM`) exigem ano+mês (e dia, quando a ref tem dia) exatos.
- Livro de 2 letras não casa por substring (`lv` não casa `lvs_T.jwpub`).
- Matriz C2.6: **76 `WRONG_EDITION` → 0**.

Exemplo: `w11 15/12` agora escolhe `w_T_20111215.jwpub`, não `w_T_20121115.jwpub`.

## Verificação

- **2.771 testes JVM / 0 falhas**
- Release assinada com a keystore de release (não debug)
- Smoke no Galaxy A34: versão 3.0.4/35, app abriu, dados existentes preservados e matcher confirmado na UI (`W11 15/12` → `w_T_20111215.jwpub`)

## Limites

- A atualização não instala por cima de build de debug (assinatura diferente).
- Edições datadas antigas que a API não entrega continuam como `EDITION_MISSING`; não é falha do app.

## Instalação

1. Baixe o `app-release.apk` e o `app-release.apk.sha256`.
2. Confira o SHA-256:

   ```bash
   sha256sum app-release.apk
   ```

3. Se você tem build de debug instalada, desinstale antes. A assinatura é
   diferente; a desinstalação apaga os dados locais.

## Privacidade

As notas ficam no aparelho. A chave da API do DeepSeek é guardada cifrada no
Android Keystore. Quando o Copilot é usado, o texto do chat e o contexto
selecionado são enviados por HTTPS à API do DeepSeek; sem chave, o app usa
apenas o motor determinístico local. O backup do Android está desligado. O
reconhecimento de voz não grava áudio; quando o modo no aparelho está
disponível, o áudio não sai do dispositivo.
