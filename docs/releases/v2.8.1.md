# Better Talker v2.8.1

**versionCode:** 26 · **ABI:** arm64-v8a · **Distribuição:** APK sideload (GitHub Releases)

## Segurança e privacidade

- **Chave DeepSeek no Android Keystore:** AES/GCM, chave não exportável. O
  DataStore guarda apenas o envelope cifrado; a chave antiga em texto claro é
  migrada automaticamente no primeiro uso.
- **Backup do Android desligado:** `allowBackup=false`. Notas e chave não vão
  para Auto Backup nem para transferência entre aparelhos.
- **APK de release assinado** com keystore própria (RSA 4096), `debuggable=false`.
  O certificado não é “Android Debug”.
- **HTTPS only:** `usesCleartextTraffic=false` e `network_security_config`.
- **WebView do jw.org** sem acesso a arquivos/conteúdo local, só HTTPS.
- **Sync desligado/experimental:** sem `google-services.json`, o app não agenda
  worker de sync. O release não inclui configuração Firebase.
- **Privacidade:** notas ficam no aparelho; quando o Copilot é usado, o texto do
  chat e o contexto selecionado são enviados por HTTPS à API do DeepSeek. Sem
  chave, o app usa apenas o motor determinístico local.

## O que mudou desde a v2.8.0

- C1: orçamentos de saída por caminho, retry por `length` e telemetria com
  `retries`.
- A1: chave no Keystore, backup desligado, assinatura de release, HTTPS/WebView.
- A2: validação no A34 com instalação limpa, migração do texto claro, importação
  de S-34, V&M 5 min, demo 4 min e chat real.

## Instalação

1. Baixe o `app-release.apk` e o `app-release.apk.sha256` do release.
2. Confira o SHA-256:

   ```bash
   sha256sum app-release.apk
   ```

3. Autorize “instalar apps desconhecidos” para o navegador/gerenciador.
4. **Se você tem uma build de debug instalada, desinstale antes.** A assinatura
   é diferente; a desinstalação apaga os dados locais. Como a distribuição com
   amigos ainda não começou, instale o release antes de criar notas definitivas.

## Limites conhecidos

- C2 (contexto/refs, `lmd` literal, 45 min monolítico), card-first e sync
  continuam fora deste release.
- **STT:** usa o serviço de reconhecimento do sistema; pode ficar indisponível
  por limite/quota do aparelho (`error=10`). O áudio não é gravado; a
  transcrição é preservada e o app oferece **Retomar/Parar**.
- **TTS:** Piper offline por padrão; não há seletor de voz na UI; o fallback
  nativo é automático.
- **Refs no chat:** pergunta com `w25.07 p. 22 §8` ainda não injeta o trecho;
  correção prevista para a v2.8.2.
- Não há export/import JSON; por isso o backup automático está desligado.
- ABI apenas arm64; aparelhos 32-bit precisam de build separado.
