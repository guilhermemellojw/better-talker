# Better Talker v3.0.6

**versionCode:** 37 · **ABI:** arm64-v8a · **Distribuição:** APK sideload (GitHub Releases)

## O que mudou

### C2.8 — foco no trecho citado e fim dos §§ globais errados

- **§ global só sem índice de página:** quando a edição tem índice de página,
  o resolvedor não busca o § no livro inteiro. `it-1 544 §4`, `it-2 890 §§5-6`
  e `it-1 587 §6` agora retornam `TEXT_NOT_FOUND` em vez de texto de outro
  artigo.
- **Foco por § na página:** quando o índice antigo tem os §§ no início do
  texto, o prompt começa no § citado e vai até o próximo § fora do range.
  Vale para `w11 15/12`, `w15 15/2`, `w07 15/9`, `w09 15/7`, etc.
- **Faixas abreviadas:** `142-4` → 142..144, `749-51` → 749..751,
  `140-1` → 140..141.
- **`cl` é página, não “estudo”:** `cl 225 §15` resolve a página 225 §15
  com o texto exato (869 chars), em vez de só 600 chars do fallback.
- **Começo+fim:** faixas/artigos maiores que 4.000 chars mandam começo e
  fim; o trecho citado no fim não se perde (`kj 142-4`, `it “Termo”`,
  `g93`, `w73`).
- **Runner da matriz:** usa o detector real (`article`/`chapter`), não a
  `DetectedRef` manual.

A medição inicial do 3.0.5 usava um runner que perdia `article`/`chapter`:
291 `PARTIAL` / 92,5%. Com o detector real, o 3.0.5 tinha **193 `PARTIAL` /
93,1%**. O 3.0.6 troca 2 refs de cobertura por correção: 3 §§ globais
errados viram `TEXT_NOT_FOUND` e 1 faixa (`it-1 749-51`) passa a resolver.
O número final é **347/375 = 92,5%**, agora sem texto de outro artigo.

## Instalação

1. Baixe o `app-release.apk` e o `app-release.apk.sha256`.
2. Confira o SHA-256:

   ```bash
   sha256sum app-release.apk
   ```

3. Se você tem build de debug instalada, desinstale antes. A assinatura é
   diferente; a desinstalação apaga os dados locais.

## Privacidade

As notas ficam no aparelho. A chave da API do DeepSeek é guardada cifrada no
Android Keystore. Quando o Copilot é usado, o texto do chat e o contexto
selecionado são enviados por HTTPS à API do DeepSeek; sem chave, o app usa
apenas o motor determinístico local. O backup do Android está desligado. O
reconhecimento de voz não grava áudio; quando o modo no aparelho está
disponível, o áudio não sai do dispositivo.
