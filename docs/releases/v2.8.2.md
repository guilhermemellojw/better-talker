# Better Talker v2.8.2

**versionCode:** 27 · **ABI:** arm64-v8a · **Distribuição:** APK sideload (GitHub Releases)

## O que mudou

- **C2a — refs com prefixo de página:** o detector aceita
  `w25.07 p. 22 §8`, `p.22`, `pág.`, `página` e `pg.`, mantendo `§`/`§§` e
  ranges. A pergunta injeta 1 trecho e a resposta usa o parágrafo; o caminho
  sem prefixo continua funcionando.
- **P0 voz:** TTS e STT não se sobrepõem. Abrir o microfone para o TTS; “Ouvir”
  fica bloqueado durante a análise. `VoiceRouter` para os dois motores ao
  falar/trocar; `TextToSpeechManager` limpa o estado em `onStop`/`onError` e
  checa o retorno de `speak`; `SpeechRecognizerManager.finish()` tem timeout
  de 5 s e falha de microfone vira erro visível.
- **Segurança/distribuição:** mantém a chave DeepSeek no Android Keystore,
  `allowBackup=false`, HTTPS only, WebView restrita e assinatura de release.

## Limites conhecidos

- **STT:** usa o serviço de reconhecimento do sistema; no A34 ele responde
  `error=10` (indisponível/limite). O áudio não é gravado; a transcrição é
  preservada e o app oferece **Retomar/Parar**. O fallback funciona.
- **TTS:** Piper offline por padrão; não há seletor de voz na UI; o fallback
  nativo é automático.
- **Refs no chat:** o caso com prefixo de página foi corrigido; o inventário
  de fontes da nota e o `lmd` literal continuam no C2.
- 45 min monolítico, card-first e sync continuam fora deste release.
- ABI apenas arm64; aparelhos 32-bit precisam de build separado.

## Instalação

1. Baixe o `app-release.apk` e o `app-release.apk.sha256`.
2. Confira o SHA-256:

   ```bash
   sha256sum app-release.apk
   ```

3. Autorize “instalar apps desconhecidos” para o navegador/gerenciador.
4. **Se você tem uma build de debug instalada, desinstale antes.** A assinatura
   é diferente; a desinstalação apaga os dados locais.

## SHA-256 do APK publicado

O hash válido é o do asset `app-release.apk.sha256` publicado no release.
Use sempre o hash do artefato baixado; builds locais podem não ser
byte-idênticos.

## Privacidade

As notas ficam no aparelho. A chave da API do DeepSeek é guardada cifrada no
Android Keystore. Quando o Copilot é usado, o texto do chat e o contexto
selecionado são enviados por HTTPS à API do DeepSeek; sem chave, o app usa
apenas o motor determinístico local. O backup do Android está desligado. O
sync permanece desligado/experimental.
