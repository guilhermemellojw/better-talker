# Better Talker v3.0.5

**versionCode:** 36 · **ABI:** arm64-v8a · **Distribuição:** APK sideload (GitHub Releases)

## O que mudou

### C2.8 — o texto da UI e o texto do prompt são o mesmo

- `RefStatus.promptText`: o prompt recebe a unidade completa; a UI continua
  com o recorte de 600 chars (`snippet`).
- `enrichContents` usa o mesmo `RoomReferenceResolver` (página+§, página,
  §, contexto) e o mesmo texto define o status “No acervo”.
- `citedSources(noteSources)` usa `promptText`/`snippet` antes de
  re-resolver; uma fonte que a UI mostra no acervo não é mais descartada
  do prompt.
- `be`/`th` são orientação de oratória (`TRAINING`), fora do bloco de
  conteúdo e do denominador.

### Matcher de edição (incluído do 3.0.4)

- Ano de 4 dígitos no nome do arquivo precisa ser o ano da edição.
- Nomes oficiais da API (`*_T_YYYYMMDD`/`*_T_YYYYMM`) exigem ano+mês (e
  dia, quando a ref tem dia) exatos.
- Livro de 2 letras não casa por substring (`lv` não casa `lvs_T.jwpub`).
- Matriz C2.6: **76 `WRONG_EDITION` → 0**.

## Limites

- **8 `TEXT_NOT_FOUND` genuínos** em livros (`bhs`, `sh`, `lff`, `jy`,
  `it-1`): o índice de página/§ não cobre a unidade citada.
- **20 `EDITION_MISSING`**: edições datadas antigas que a API não entrega
  no dia exato; não é falha do app.
- **291 `PARTIAL`**: texto real por página/§/contexto, mas recorte
  aproximado; a conferência da unidade é humana.

- O tablet recusou a instalação do release 3.0.4 com

## Instalação

1. Baixe o `app-release.apk` e o `app-release.apk.sha256`.
2. Confira o SHA-256:

   ```bash
   sha256sum app-release.apk
   ```

3. Se você tem build de debug instalada, desinstale antes. A assinatura é
   diferente; a desinstalação apaga os dados locais.

## Privacidade

As notas ficam no aparelho. A chave da API do DeepSeek é guardada cifrada no
Android Keystore. Quando o Copilot é usado, o texto do chat e o contexto
selecionado são enviados por HTTPS à API do DeepSeek; sem chave, o app usa
apenas o motor determinístico local. O backup do Android está desligado. O
reconhecimento de voz não grava áudio; quando o modo no aparelho está
disponível, o áudio não sai do dispositivo.
