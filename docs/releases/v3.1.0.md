# Better Talker v3.1.0

**versionCode:** 41 · **ABI:** arm64-v8a · **Distribuição:** APK sideload (GitHub Releases)

## O que mudou

### STT local validado (opt-in)

- O motor **sherpa-onnx NeMo CTC pt-BR (int8)** deixa de ser experimental:
  medido com fala humana real no A34, **WER 2,9% no pipeline do app**
  (média de 3 amostras; 7,7% na fala rápida a ~183 wpm).
- **Default continua Sistema:** Configurações → Voz → Motor de reconhecimento.
- Para ativar: **Sherpa (offline)** + baixar o modelo PT-BR (~125 MB, sob demanda).
- Áudio 100% local; nada é gravado em disco; fallback automático para o sistema.
- Modelo liberado ao fim de cada treino; recarrega em ~2 s no próximo.
- **Licença do modelo:** NVIDIA NeMo CC-BY-NC-4.0 (não comercial) — aviso em Configurações → Voz.

### Medição de WER (harness)

- `SttWerTest` mede **MODEL_WER** (WAV inteiro) e **PIPELINE_WER**
  (VAD + decode por segmento, o caminho real do app).
- `scripts/stt-wer.sh` + `docs/operations/stt-wer.md` para repetir a medição.
