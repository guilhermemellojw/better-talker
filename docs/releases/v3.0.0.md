# Better Talker v3.0.0

**versionCode:** 31 · **ABI:** arm64-v8a · **Distribuição:** APK sideload (GitHub Releases)

## O que mudou

Esta é a versão de produto que reúne o Copilot confiável, o discurso de
45 minutos, o status único das fontes, o seletor de voz/STT e os fluxos de
Treino e Apresentar.

### Copilot e fontes

- **Status único das fontes:** edição (`ausente/baixando/indexando/falhou/
  não suportada/pronta`) + texto (`resolvido/parcial/não encontrado/ambíguo`)
  + ação (`baixar/reindexar/confirmar/abrir/aguardar/nenhuma`).
- Checklist, inventário do prompt e card do chat usam a MESMA lista do
  `NoteSourcesResolver`; o modelo não reduz mais tudo a “publicação ausente”.
- **Card “Fontes necessárias”** com baixar, reindexar, confirmar edição,
  acompanhar, “Já baixei — atualizar” e “Continuar sem”.
- **Gate determinístico:** pergunta específica sobre ref bloqueante espera a
  decisão do usuário; pedido amplo segue com aviso; “Continuar sem” registra
  a ausência no prompt e nunca inventa o conteúdo.
- Inventário do prompt com motivo + ação por referência e a regra explícita:
  não dizer que a referência não existe, não inventar texto e não usar outra
  edição.
- **45 min monolítico:** BODY sem subpontos em 2 partes (23+22 min), com
  stitch, progresso, continuação e retry de extensão no gerador. A34: 5.711
  de ~5.850 palavras (97,6%) nas 2 partes.

### Voz e STT

- **Configurações → Voz:** motor Piper offline ou voz do sistema, lista de
  vozes pt-BR, voz padrão, teste de voz e switch de reconhecimento no aparelho.
- **STT on-device:** usa o reconhecedor do próprio aparelho quando existe;
  envia `EXTRA_PREFER_OFFLINE`; se indisponível, avisa e usa o serviço do
  sistema. O áudio não é gravado pelo app.
- TTS e STT continuam sem se sobrepor (P0 voz).

### Chat, cards e apresentação

- Streaming com markdown, cursor com fade, morph Enviar/Parar, haptics e
  TalkBack; parcial cancelado preservado.
- Card-first com estados, ações, undo, verificação warn-only e gate do “Sim”.
- Treino MVP e Apresentar live validados no A34.
- Contexto S-34, inventário de refs, dossiê e RAG no mesmo turno.

## Limites conhecidos

- **STT:** depende do serviço/pacote do aparelho. No A34 o on-device abriu
  normalmente; em aparelhos sem o pacote, o app avisa o fallback.
- **TTS:** o Piper tem voz única; o seletor cobre as vozes do sistema
  (inclusive como fallback). Sem controle de velocidade/tom nesta versão.
- **45 min com subpontos:** continua na fila por subponto; esta versão cobre
  o BODY monolítico sem subpontos.
- **Refs por página sozinhas:** continuam sem resolver; cite §/capítulo junto.
- ABI apenas arm64; aparelhos 32-bit precisam de build separado.
- O gate de fontes não baixa nada sozinho: as ações são explícitas no card.

## Instalação

1. Baixe o `app-release.apk` e o `app-release.apk.sha256`.
2. Confira o SHA-256:

   ```bash
   sha256sum app-release.apk
   ```

3. Autorize “instalar apps desconhecidos” para o navegador/gerenciador.
4. **Se você tem uma build de debug instalada, desinstale antes.** A assinatura
   é diferente; a desinstalação apaga os dados locais.

## Privacidade

As notas ficam no aparelho. A chave da API do DeepSeek é guardada cifrada no
Android Keystore. Quando o Copilot é usado, o texto do chat e o contexto
selecionado são enviados por HTTPS à API do DeepSeek; sem chave, o app usa
apenas o motor determinístico local. O backup do Android está desligado. O
reconhecimento de voz não grava áudio; quando o modo no aparelho está
disponível, o áudio não sai do dispositivo.
