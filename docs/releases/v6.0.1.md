## O que corrige

### “Novidades do 6.0” automático

- O sheet automático do 6.0 não aparecia no primeiro lançamento do build
  71/6.0. O gate decidia `SHOW`, mas gravava `upgrade_v6_seen` antes de
  `showV6UpgradeSheet = true`; como `seen` é uma das chaves do próprio
  `LaunchedEffect`, a mudança cancelava a coroutine antes de o sheet abrir.
- Agora o sheet é aberto **primeiro**; `seen`/métrica são gravados depois.
  A decisão do aviso 5.0 também é concluída antes de liberar o gate do 6.0,
  para os dois sheets não competirem.
- Resultado: no primeiro lançamento do build 73/6.0.1 com notas, o sheet dos
  quatro cards aparece uma vez; “Agora não” não reabre; a Ajuda continua
  abrindo “Novidades do 6.0” manualmente.
